- 사이트: https://mangang0713.github.io/fandom-timeline/
- 프롬프트 복사 버튼: 전체 인터뷰 지시문을 클립보드에 복사합니다.
- ChatGPT로 이동 버튼: https://chatgpt.com/ 을 새 탭으로 엽니다.
- 사용자는 새 채팅에 복사한 프롬프트를 붙여 넣습니다. 비공식 URL 자동입력 방식은 사용하지 않습니다.
- 카드: 4:5 파스텔 텍스트 인포그래픽, 실존 인물 사진 및 생성형 인물 얼굴 이미지 전부 금지, 다음 최애 추천 3명 포함.
- 백엔드·API 키·분석용 DB 없음. 이 사이트는 방문자에게 이름·덕질 내역을 입력받거나 저장하지 않습니다.
- 이미지 생성은 방문자의 계정 기능과 사용 한도에 따릅니다.

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).
